# 大批量持久导出

这是全新实现计划 V3 Task 7 的后续实施约束。命名模板和同步导出已经交付；本文规定持久任务的目标行为，不代表任务已实现。

当前已实现独立的逐行文件生成核心及真实磁盘测试，尚未接入下面的持久任务 API、执行器和界面。核心由 Rust 调用方提供空的私有文件与持有租约的 XLSX 工作目录，返回已重新读盘核验的文件句柄、长度、SHA-256 和行数；失败不返回可发布结果，工作目录的持久登记与清理由任务层承担。

## 输入与结果

新增 `/api/v1/data-tools/exports`，与现有同步下载并存。创建使用规范 UUID `requestId`、`format`、`maxRows` 和 `source`：资源来源保存明确资源、有序字段/表头、受控条件及排序；模板来源提交精确模板 ID/版本，服务器解析为同一不可变配置。创建后修改/删除模板不改写任务。

默认最多 100000 行，可显式设为 1–1000000 行，超过请求行数失败而不截断；CSV/XLSX 最终内容最多 5 GiB，单元格仍最多 16 KiB、最多 32 列。导入继续使用已有的 6 MiB/2000 行限制，异步导出不放宽导入契约。每账号最多两个活动任务、服务最多八个活动任务和两个执行器，额度检查、创建与审计在同一事务中完成。

任务按原操作者和 UUID 绑定规范输入指纹；相同请求重放返回原任务，不同输入返回 409。公共接口包括分页列表、ID 详情、按 requestId 查询、取消、显式重试和受控内容下载。所有查询先检查操作者和当前资源读取权限，其他操作者即使为 Owner 也得到 404。公开结果只包含状态、进度、文件名/类型/大小/摘要、期限和安全错误码，不返回存储定位、内部租约、原生路径或行清单。

## 授权

共享模板只提供配置。创建需要 exports.write 和资源读取权限；查询/下载需要 exports.read 和资源读取权限。执行器重新读取活动用户及当前角色权限，生成查询取创建时的数据范围与当前范围交集。任务的创建范围不能随着账号后来扩权而扩大。

用户资料导出另外保存分批的私有行 ID 清单，每批最多 1000 个 ID；清单不包含密码、令牌或导出的字段值。生成后发布前、每次下载前，按当前账号范围核对整份清单，任一行已不在可读范围则拒绝发布/下载并提示重新导出。这样可以处理任务完成后角色范围或被导出用户的角色成员关系变化。普通文件的 files.read 或文件所有者范围不能替代这里的资源授权，导出结果不注册成可由普通 `/files` 路由直接读取的文件。

下载授权以本次请求开始时重新取得的身份和范围为准，与现有 API 请求边界一致；不声称可以收回此前已下载到操作者电脑的内容。清单与结果有相同保留期限，清单核对失败不得先发送部分文件正文。

## 生成、发布与恢复

CSV 逐行写入；XLSX 启用当前锁定 rust_xlsxwriter 的 constant_memory 模式，按行写入服务私有工作目录。MongoDB 使用明确投影和有界游标批次，字典明细的关联不得形成随全量行数增长的 BSON 数组。单元格、行数、中间内容预算、最终长度、取消和任务时限在生成过程中检查，不能把整份表格或文件装入 Vec/base64。

生成核心复用原有表头/单元格校验及 CSV 公式保护。CSV 的临时内容预算按实际编码字节检查；XLSX 为固定文件内容、每行/单元格开销和最多八倍的字符转义预留保守预算，超限明确失败。完成时比较写入时与重新读盘的长度和摘要，文件被改写或截断后不能取得成功结果。默认输出预算和 XLSX 中间内容预算各为 5 GiB，不等同于合计只占 5 GiB 磁盘。

每项任务使用私有工作目录和独占租约，目录名只能由服务器生成的 UUID 派生。生成完成后同步并重新读取实际磁盘内容计算长度和 SHA-256，再接入现有 VerifiedSource/BlobStore 校验链。临时文件与 XLSX 中间文件只在该工作目录内生成；重启维护只处理已登记且不持有活动租约的确切目录，不扫描或删除用户目录。

持久状态区分 queued、running、publishing、reconciling、unknown、completed、failed、cancelled 和 expired。每次执行取得新的租约令牌与代际，进度、发布和结果提交均检查令牌；取消与最终提交使用同一事务栅栏，取消成功后旧执行器不能公布结果。任务运行最长 30 分钟，租约约每 10 秒续期、60 秒到期；停止服务取消当前工作，重启从持久状态继续。

调用对象存储前先持久登记独立内容候选、长度、摘要和存储配置 ID。外部写入、数据库提交或响应不明确时先检查该候选，已存在且完整则提交同一结果；不能因一次超时/404 就自动换内容 ID 再写。显式重试也先确认原候选；确需重建时使用新代际和独立候选，旧未知候选继续追踪和精确清理。

结果、完成审计、行清单和文件元数据原子变为可见。审计失败不能留下已公开结果。存储配置的修改/删除引用检查纳入任务、候选和清理记录，避免配置变化使未决内容失去定位。复用本地/S3 驱动和完整性校验，不复制第二套对象存储实现。

## 保留、界面与验收

完成的内容保留 24 小时，接口到期立即拒绝下载，再由有界后台维护精确删除内容和私有清单；轻量任务/请求回执继续保留。取消、过期、失败和未知写入的清理状态可查询，清理失败保留定位，不能用删除元数据伪装清理成功。

数据工具增加持久导出按钮、分页历史、状态/行数/进度、查询、取消、显式重试与下载。首次发送前保留服务器/账号范围内的请求 ID 和不含内容的操作标记；响应丢失或重启后先查询，不能自动新建重复任务。下载复用 ApiClient 的单次刷新、会话代际取消和 FileSink 完整性链；浏览器 128 MiB 缓存上限与原生 5 GiB 磁盘能力继续分开说明。

验收需要真实超过 2000 行的 CSV/XLSX，类型及公式防护、命名模板快照、分页、权限撤销和成员关系变化、任务并发额度、取消/提交竞争、丢失响应、执行器/服务终止后恢复、本地/S3 结果未知确认、结果过期清理及配置引用保护。原生 OS 对话框、安装包和真实大文件验收仍遵守用户暂停电脑自动操作的决定，不能由无界面测试替代。
