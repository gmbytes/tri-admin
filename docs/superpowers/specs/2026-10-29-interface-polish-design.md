# Tri Admin 界面精修

## 目标与边界

为现有管理人员提供清晰、耐看的日常操作界面。只调整工作台、用户、角色、菜单、权限、日志、文件七个模块及共享登录和个人中心的视觉呈现；不添加业务功能、接口、权限或演示数据。

## 视觉方案

按用户补充要求采用「Art Design Pro 的细节 + 青花蓝白」，整体清新优雅。导航使用浅瓷白，青花蓝用于选中态、图标和主按钮，内容区保留舒展留白。参考成熟模板的表格、表单与弹窗处理，不引入其业务模块、依赖或演示数据。

基础颜色：青花深蓝 `#173B70`、操作蓝 `#245FC5`、浅瓷蓝 `#EDF3FF`、瓷白 `#F6F8FC`、纸白 `#FFFFFF`、正文 `#243B5B`。次要文字使用 `#62748E`，成功与危险色仍表达各自状态。深蓝只保留在登录的品牌区域。

字体使用本机 `Segoe UI Variable` / `Microsoft YaHei UI` / `PingFang SC`，避免外部字体请求。正文 14px、辅助文字 12px、标题 28px，数字使用等宽数字特性。所有内容左对齐。

布局：导航固定在左，顶部工具栏轻量呈现会话与连接，主内容最大宽度约 1480px。工作台四项真实统计组成统一面板，以细分隔线体现关系；快捷入口以图标和明确文字呈现。表格、表单和弹窗使用同一套间距、圆角和焦点样式。

## 设计复核

去掉与操作无关的全大写英文标签、装饰性横幅、重复阴影与标语。把视觉识别集中在青花蓝白导航与按钮上，数据区保持安静。保留真实统计和已有入口，不用假图表填空白。

窄屏使用紧凑导航，表格在自身区域滚动；表单和弹窗保持在视口内。弹窗的标题、内容、底部操作分区明确，只有内容区滚动，取消与保存始终可达；角色授权以中文分组横向组织。确认框、文件选择区、输入焦点和错误提示统一精修。键盘焦点清晰，减少动态效果设置有效。登录输入、保存、删除、重置密码等行为不变。

## 验证

运行现有前端单元测试、类型检查、生产构建和浏览器端到端测试。新增窄屏可用性回归，覆盖工作台无整页横向溢出、七个导航入口和角色弹窗。使用实际运行的浏览器检查工作台、列表、弹窗及文件页面并保存截图。
