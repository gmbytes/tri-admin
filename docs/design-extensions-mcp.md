# 扩展库与 MCP

本设计细化已授权的 Task 9 B，继续使用新 Rust/MongoDB/REST/Vue。旧工程只核对功能目的：Skill 说明及脚本/资源/参考/模板维护、全局约束、打包导出，以及 MCP 工具发现/调用与进程生命周期；不复制旧模型、路由、Go 代码或生命周期。

Skill 内容使用 [Agent Skills 格式](https://agentskills.io/specification) 的 SKILL.md/YAML 元数据和 Markdown，配套文件作为数据保存。插件采用本项目 tri-plugin.json v1 描述，组合 Skill、工具绑定和 MCP 能力引用。工具提示或 allowed-tools 字段不授予后台权限。MCP 使用 [2026-07-28 协议](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports) 和固定 rmcp 3.5.1；客户端显式 Discover 新生命周期，不使用 Auto/Initialize 回退。STDIO、Streamable HTTP、服务端实际业务工具与进程管理分别验收，不能用只读 echo 或目录项代替交付。

扩展库支持新建/安装、按版本编辑元数据和配套文件、启停、卸载、历史、读取和原包/规范包导出；全局约束为有界版本化资源。创建和安装带请求 UUID，版本、归属、审计与不可变修订同事务。记录按创建者及当前 all/self/roles 范围控制。修改内容生成新修订，旧修订不重写；卸载不把旧 ID 重新绑定到同名新包。首次安装和内容更新默认停用，用户检查后再启用，安装与启用本身均不自动执行代码。

包只在受控虚拟文件树内保存，不向请求指定的主机目录解包。ZIP 最多 4 MiB、256 个文件、单文件 4 MiB、展开总量 16 MiB；拒绝目录穿越、链接、设备路径、不可移植路径和大小写/规范化冲突。SKILL.md 最多 256 KiB，前置信息最多 16 KiB；YAML 禁用包含、环境替换、锚点/别名和合并，设置结构/标量预算，错误不回显内容。预览仅有界 UTF-8 文本，二进制资源保留原字节；包内说明是待管理的数据，不是当前代理的指令。

MCP 子进程使用部署时批准的命令能力 ID、固定程序/参数和受控工作目录，不通过 HTTP 接受任意 shell 命令；清空继承环境并仅传明确配置。目录配置不是操作系统沙箱，程序由部署者信任。停止/超时/异常需要确认子进程退出，Windows 隐藏窗口并处理进程树，服务重启不假报旧进程仍运行。HTTP 目标沿用现有 DNS/TLS/重定向/代理限制，凭据使用加密引用且不回显或记日志。

工具调用保存请求身份、参数摘要、状态和安全结果引用；不确定的远端或进程效果标为 unknown，不盲目重发。工具发现的注解不是授权，执行仍核对当前调用者及实际后台操作权限。插件绑定仅指向已实现的操作或批准的 MCP 能力，不执行任意模板表达式。主后台通过现代 MCP 服务暴露实际字典/参数/代码生成等能力，管理 JWT/PAT 和开放用户身份不能混用。

阶段先实现包解析/编辑/导出与持久扩展库，再实现真实 MCP 客户端、进程监督、HTTP 和业务工具服务，最后 UI、权限、重启/超时/撤销及完整回归。协议夹具、真实本机进程和实际外部上游分别报告；AI 与持久工作流仍按后续 C/D 完成。

扩展修订在 MongoDB 中只保存最大 4 MiB 的原始 ZIP 与元数据，不把最多 16 MiB 的展开树塞进单条文档。文本预览、文件修订和启用检查从原 ZIP 重建并核对摘要；导出保持该修订的原始字节。内容修订保留名称、类型和旧修订，启停只增加记录版本，卸载保留原 ID 的可授权历史。创建和修订按当前操作者/UUID 保存结果快照；查询回执不会转向同名的新安装或重做已提交变更。

全局约束使用独立 `skills.constraints.write` 权限并要求当前全部数据范围，读取沿用 `skills.read`。普通 `skills.write` 只允许在自身授权范围维护扩展，不能改全局规则。约束每次更新保留独立版本并与审计同事务。包内容仍是数据，约束文本也不会被本服务当作 shell 或脚本执行。

当前已交付包核心、扩展库 API 和管理界面；含工具绑定或 MCP 贡献的插件可作为停用内容保存，在后续能力解析和生命周期接入完成前不能启用。此阶段限制不是最终 MCP 交付，不能据此将 Task 9 B 标为完成。
