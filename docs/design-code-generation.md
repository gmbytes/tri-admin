# 新工程代码生成

本设计细化已授权的 V3 Task 9，不改变其余 Skills/MCP、AI、工作流和 tok 范围。以下为本阶段工程裁定；没有旧接口、旧模型或 SQL 模板。

生成产物为独立 Rust/MongoDB/Vue 工程，包含受认证保护的资源 CRUD、分页/前缀搜索、版本冲突、软删除、审计和 Vue 操作页面。运行核心使用同一套可测试 Rust 源码，随产物一起打包，避免模板复制后行为漂移。产物不依赖当前机器的绝对路径，不包含真实数据库地址、密码、签名材料或管理会话。

资源描述包含安全的资源标识、显示名称和 1–40 个有序字段。字段类型为文本、整数、小数、布尔、时间和文本列表；支持必填、文本前缀搜索及必填文本唯一性。字段标识、元数据保留名、重复、长度、数字安全范围和日期均严格验证，规范化 values 每条最多 64 KiB，使最大 100 条分页仍处于客户端 8 MiB 响应界限内。值位于 values 对象，服务端决定 ID、ownerId、版本和时间；更新提供原版本及完整 values，不接受原始 BSON、任意查询、路径、代码或模板表达式。唯一性按 ownerId 和活动记录建立，防止跨所有者存在性泄露。

独立工程的管理员身份与主 TRI ADMIN、开放应用身份分开。部署时提供独立签名密钥，在本机 CLI 交互创建管理员；密码为 Argon2id，短时 JWT 绑定可撤销的数据库会话，每次业务重新读取有效管理员、权限和数据范围。产物初始提供 read/write 与 all/self，不复制整个主后台的角色管理。登录/注销可用，15 分钟后重新登录；本模板不签发长期刷新凭据。登录限流、正文大小和 CORS 有界。写入在 MongoDB 副本集事务中再次核对身份、范围、版本，并与安全审计同提交。Vue 仅在内存保存访问凭据，退出或切换服务时清除。

生成器本身使用 codegen.read/write、当前管理身份及审计。定义可版本化修改/删除，生成记录绑定定义版本、模板版本和内容摘要；按请求 UUID 查询历史，下载生成包前重新授权。预览和 ZIP 只包含固定、受控的相对文件名，不能向服务机器任意目录写入，也不执行用户输入。生成历史保留不可变描述快照，修改定义不改变旧产物。页面只在实际接口和组件均存在后加入菜单。

验收先覆盖描述与值验证，再覆盖真实副本集的认证、隔离、并发、审计回滚和软删除；随后生成代表全部字段类型的产物，在独立目录实际 cargo build/test、npm build/test，并通过真实 HTTP 操作生成服务。权限只读、版本冲突、预览/下载摘要、生成历史和新页面由主工程测试。协议夹具与真实外部上游证据分开；产物可运行不等于整个 Task 9 或目标完成。
