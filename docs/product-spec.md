# tri-admin 产品规范

当前范围以用户 2026-10-28 确认的[游戏管理收敛方案](superpowers/specs/2026-10-28-game-focused-scope-design.md)和[实施计划](superpowers/plans/2026-10-28-game-focused-retirement.md)为准，覆盖 V3 通用平台和开发模块。无旧项目接口或代码兼容要求。

| 领域 | 交付能力 |
| --- | --- |
| 工作台 | 服务状态、资源概览、最近活动、游戏服状态入口 |
| 认证 | 登录、刷新、注销、当前用户、会话撤销、限流 |
| 权限 | 用户、角色、操作码权限、菜单和按钮控制、数据范围、审计 |
| 基础管理 | 用户、角色、菜单、API/权限目录 |
| 日志 | 登录、操作、应用错误，筛选、分页与受控清理 |
| 文件管理 | 分类、分片上传/续传、授权下载与必要存储驱动 |
| 当前范围 | 仅上述七个模块，不自动增加游戏业务或其他模块 |
| 桌面 | Windows 安装、服务器设置、网络反馈、会话保存、文件对话框、更新与重启 |

角色初始包含 Owner（受保护管理员），后续可配置 Operator/Viewer。全部资源使用字符串 ID 和标准 HTTP 状态；删除优先软删除或明确的业务删除规则。

数据范围验收包括全部、自身及指定角色范围，使用用户资源验证聚合、分页前过滤、范围委派和交叉授权。客户/客户端管理业务模块已按用户明确要求从产品范围移除，后续不增加对应页面、菜单、接口、权限或数据集合。

字典、参数、配置中心、数据工具、API Token、开放应用、代码生成、Skills/插件、MCP、AI、工作流和现有配置版本管理均由用户取消，完整移除入口、接口、权限及专属依赖。Codex 本机 frontend-design 是开发技能，不是后台产品模块。
