## Task 3 验证与裁定

- 新接口 `/api/v1/auth/login`、`refresh`、`logout`、`me`；Argon2id、HS256 严格 issuer/audience/有效期、15 分钟访问令牌及 7 天可撤销会话。
- 刷新令牌只保存 SHA-256 摘要，原子轮换；复用和并发复用会提交会话撤销，再返回拒绝结果。

- 新增实际失败测试：认证模型未就绪时原先仍返回就绪 200，修正后 503；更换用户名原先绕过 IP 限流，修正后 429。

## Task 6：配置导入预览 API（2026-10-25）

- 严格校验新包格式、schema、稳定键唯一性、字段、类型、接口依赖和导入后的完整菜单图；复用既有领域校验，不解析旧格式。

- 上传 UUID 与创建者绑定，同参数返回原会话当前状态，异参数冲突；默认存储在首次创建时确定，后续重放不随默认值改变。未发布会话只对创建者可见，每账号最多 32 个活动会话。
- 固定 4 MiB 分片、5 GiB 规范上限、索引/精确长度/SHA-256 校验，允许乱序和同内容重试，异内容不覆盖。候选在本地 I/O 前登记，接收清单、计数与审计同事务；并发读取请求最多 8 个，截断/中止不会占住后续容量。
- 取消先持久提交状态，再按精确候选 ID 每批最多清理 100 个；清理失败保留任务并可重试，写入中的尝试不假报已清理。默认设置、活动文件、未结束上传及待清理内容会共同保护存储配置，锁顺序为 settings 后 files，引用创建与删除竞争不能同时成功。
- 最初 5 项测试因缺少入口返回 404；扩展测试复现通配 MIME 被接受、清理审计缺失及分片摘要头跨域许可缺失，均先失败后修复。22 项上传测试涵盖并发、重放、取消、失败回滚、清理恢复、配额、重建服务状态、引用竞争、跨域预检及边界。
- 隔离数据库分别建立 2000 条分类与上传记录，常见列表/名称/前缀查询取 20 条时检查不超过 20 个文档、21 个键；上传分页在查询前固定创建者，计数不混入另一账号。
- 最终完整 Rust 常规测试 169 项通过；3 项外部 S3 门禁本轮保留 ignored，驱动未改变，沿用上一阶段实际运行证据。Clippy/格式、工具 4 项、客户端 28 项通过，API 目录/配置中心做针对性页面回归。
- 本机实际 HTTP 先保存尾片，再确认 API 进程更换后恢复清单、补传 4 MiB、验证 UUID/分片重放与冲突、取消并清理；临时分类/存储已删除，验证会话注销，服务 ready 200。续传上下文仅包含测试元数据，不持久保存登录凭据。
