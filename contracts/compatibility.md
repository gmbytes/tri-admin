# 兼容约束

- 迁移清单以大写 HTTP 方法与区分大小写的路径共同标识；查询字符串不是路由标识的一部分。
- Swagger 的 `{id}` 和 Gin 的 `:id` 只在清单中规范化；接口 JSON 字段不自动改名。
- 业务成功 `code=0`，业务失败保留旧 `code=7` 与原 HTTP 状态规则。
- 保留 `ID`、`CreatedAt`、`UpdatedAt` 及分页 `list/total/page/pageSize`。
- 数字与字符串、null 与空对象、字段缺失与显式 null 必须能在契约比对中区分。
- 只允许显式登记的时间、UUID、令牌等叶节点归一化；权限结果、业务错误和 ID 不允许被忽略。
- 夹具保存前拒绝明文密码、令牌、认证头和带密码的数据库 URL；认证值应替换为 `<redacted>`。
- 未采集真实数据库/HTTP 响应前，合成夹具不作为功能已经兼容的证据。
